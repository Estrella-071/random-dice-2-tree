# Random Dice 2 骰子樹

這是一個以繁體中文整理的《Random Dice 2》骰子樹瀏覽器。地圖保留遊戲樹的節點與線段，說明文字改放在提示框中，方便閱讀完整效果與解鎖條件。

## 使用方式

直接部署 `site/` 目錄即可。若要在本機預覽，請在 `site/` 目錄啟動靜態伺服器，例如：

```powershell
python -m http.server 4173
```

然後開啟 <http://localhost:4173>。

## 操作

- 滑過節點：查看節點資料。
- 點擊節點：固定提示框；按 `Esc` 或提示框右上角的 `×` 關閉。
- 滾輪、觸控雙指或右下角按鈕：縮放地圖。
- 拖曳地圖：移動視野。
- 左上角小地圖：點擊位置移動視野，框線表示目前畫面範圍。
- 右上角搜尋：搜尋骰子、符文、分支、節點效果與圖示名稱。

## 資料

- `data/dice_tree.json`：節點、成本、效果與分支資料。
- `data/dice_tree.svg`：自包含的骰子樹 SVG，包含節點圖示與線段。

資料來自 Random Dice 2 iOS 1.0.0 客戶端的本地資源整理；網站只讀取上述兩個靜態檔案。
