# Random Dice 2 骰子樹互動地圖

這是一個以繁體中文整理的《Random Dice 2》骰子樹互動瀏覽器。

## 🌟 特色

- **完整全樹繪製**：收錄五大派系（自然、工學、魔法、秩序、混沌）全 239 個節點與連線脈絡。
- **高科技選取光效**：忠實還原各派系專屬科技選取框與順暢跑馬燈。
- **精準數值與階級**：同步 8/20 最新官方修正數值與階級消耗。
- **極致響應與手勢**：支援桌機平移縮放、手機底部抽屜（Bottom Sheet）與雙指手勢。
- **直覺搜尋與前置導航**：支援關鍵字即時搜尋與前置升級路徑高亮。

## 🚀 本地預覽

進入 `site/` 目錄並啟動靜態伺服器：

```bash
# 使用 Node.js
npx serve site

# 或使用 Python
python -m http.server 3000 --directory site
```

開啟瀏覽器造訪 `http://localhost:3000`。
